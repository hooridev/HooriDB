HooriDB is a desktop database manager for PostgreSQL, MySQL, MariaDB, and MongoDB. It runs on Windows 11 (x64) and Linux (x64).

<Shot name="overview" alt="HooriDB showing the Workspace tree on the left and the orders table open in a tab" />

## What you can do

- Keep database connections in nested folders with color markers in the [Workspace](/docs/features/workspace), with passwords stored in your operating system's keyring when you leave **Save in system keyring** on.
- Connect to several servers at once and [browse](/docs/features/browse) their databases, schemas, tables, views, and columns.
- Read [table and view data](/docs/features/table-data) in pages, copy cells, and inspect long values or formatted JSON in the value panel.
- Write and run SQL in [consoles](/docs/features/console) with completions, error underlines, pinned result tabs, [transaction controls](/docs/features/transactions), and statement [history](/docs/features/history).
- Browse [MongoDB](/docs/features/mongodb) databases and collections, look at documents as a grid, JSON, or a tree, and run shell statements in a console, on a connection that can be read-only.
- Use the [command palette](/docs/features/command-palette) to run commands and open tables by name, and tear tabs off into [separate windows](/docs/features/tabs-and-windows).

HooriDB is in early development. You cannot edit, filter, or sort rows in the table grid yet. See [Limitations](/docs/reference/limitations) for what is not supported yet.
