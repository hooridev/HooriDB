## Window and navigation

These shortcuts work in both the main window and torn-off tab windows.

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | **File > New console**: open a new console |
| `Ctrl+W` or `Ctrl+F4` | **File > Close tab**: close the active tab |
| `Ctrl+Shift+P` or `F1` | **View > Command palette…**: open the command palette |
| `Ctrl+P` | **Go > Go to table…**: search and open tables and views (`@` mode) |
| `Ctrl+PageDown` or `Ctrl+Tab` | **Go > Next tab**: switch to the next tab in the window |
| `Ctrl+PageUp` or `Ctrl+Shift+Tab` | **Go > Previous tab**: switch to the previous tab in the window |
| `Ctrl+Shift+PageUp` / `Ctrl+Shift+PageDown` | Move the active tab left or right |
| `Ctrl+0` | **Go > Workspace**: focus the Workspace tree (main window) |
| `Ctrl+1` | **Go > Tab content**: focus the active tab's grid or console editor |

## Workspace tree

| Shortcut | Action |
| --- | --- |
| `Enter` | Connect to the selected connection, or open the selected table or view |
| `Right` | Unfold the selected item, or move to its first child |
| `Left` | Fold the selected item, or move to its parent |

## Table and result grids

| Shortcut | Action |
| --- | --- |
| `Shift+Enter` | Open or close the value panel (works in the grid and inside the value panel) |
| `Ctrl+C` or `Ctrl+Insert` | Copy selected cells or rows (table grids, console result grids, and History) |
| `Ctrl+A` | Select all cells in the grid |

## Console

| Shortcut | Action |
| --- | --- |
| `Ctrl+Enter` | **Run**: run the selection, or the statement at the caret |
| `Ctrl+Shift+Enter` | **Run all**: run every statement in the editor |
| `Ctrl+Space` | Open the completion list at the caret |
| `Ctrl+Shift+C` | **Commit**: commit the open transaction |
| `Ctrl+Shift+R` | **Rollback**: roll back the transaction (SQL consoles only, as is Commit) |

## Dialogs, completions, and command palette

| Shortcut | Action |
| --- | --- |
| `Enter` | Confirm the dialog's default button, insert the selected statement in History, accept a completion, or run the highlighted palette item |
| `Tab` | Accept the highlighted completion in a console |
| `Escape` | Close the open dialog, completion list, or command palette |
